## 1. 鉴权与角色

```http
Authorization: Bearer <JWT>
```

| 模块 | 路径前缀 | JWT `role` | 附加校验 |
|------|----------|------------|----------|
| 老人社群 / 好友 / 私聊 | `/v1/elder/...` | `elder` | — |
| 子女预览 | `/v1/child/elders/{elderProfileId}/interest-communities` | `child` | 与 `{elderProfileId}` **active 家庭绑定** |
| 媒体下载 | `/v1/community-voice|image/...` | `elder` 或 `child` | 校验消息归属 / 入群或线程参与 |
| 老人头像 | `POST /v1/elder/profile/avatar` | `elder` | — |

## 2. 通用约定

### 2.1 ApiResponse 信封

```json
{
  "code": 0,
  "message": "success",
  "data": { }
}
```

| code | 含义 |
|------|------|
| `0` | 成功 |
| `4000` | 参数校验失败 |
| `401` / `4011` | 未登录 / token 过期 |
| `403` | 无权限（角色、未入群、非绑定子女等） |
| `404` | 资源不存在 |
| `409` | 业务冲突（重复入群、重复加好友等） |

> 多数业务错误 **HTTP 仍为 200**，客户端以 `code != 0` 判断。媒体下载接口返回二进制流，不走 JSON 信封。

### 2.2 scopeKey 规则

与前端 `CommunityScope` 一致：

| 优先级 | 格式 | 示例 |
|--------|------|------|
| 1 | `phone_{11位手机号}` | `phone_13800138001` |
| 2 | `elder_{elderProfileId}` | `elder_12` |
| 系统 | `system` | 群助手（欢迎语等，**前端列表会过滤**） |
| 演示群友 | `demo_peer_*` | `demo_peer_wang`（见 `community_demo_peer_profiles`） |

### 2.3 消息分页（群聊 / 私聊共用）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `before` | string | 无 | 游标：返回比该 `id` **更早** 的消息 |
| `limit` | integer | 50 | 最大 **200** |

响应 `MessagePage`：

```json
{
  "items": [ /* 按 createdAtMillis 升序 */ ],
  "hasMore": true,
  "nextBefore": "msg_xxx"
}
```

**首屏**（无 `before`）：应返回**最近一页**升序记录，便于客户端打开后滚到最新消息。

### 2.4 时间字段

- 响应优先提供 **`createdAtMillis`**（long，毫秒）。
- 库表 `DATETIME(3)`，序列化时转毫秒。

### 2.5 固定社群 ID

`interest_communities.id` 枚举（演示库）：`taiji`、`calligraphy`、`fitness`、`travel`。

## 3. 数据模型

### 3.1 InterestCommunityBrief — 社群目录项

```json
{
  "id": "taiji",
  "name": "太极晨练群",
  "shortDescription": "一起练站桩、步法与呼吸节律…",
  "previewIcon": "🥋",
  "memberHint": "约 328 人在练",
  "joined": true
}
```

### 3.2 CommunityMessage — 群聊 / 私聊消息（共用）

```json
{
  "id": "msg_taiji_001",
  "communityId": "taiji",
  "role": "elder",
  "senderDisplay": "张建国",
  "senderScopeKey": "phone_13800138001",
  "senderAvatarUrl": "/uploads/avatars/phone_13800138001.jpg",
  "senderEmoji": null,
  "kind": "voice",
  "textContent": "",
  "audioUrl": "/uploads/community_voice/uuid.m4a",
  "imageUrl": null,
  "durationMs": 4200,
  "createdAtMillis": 1712716200000,
  "mine": true
}
```

| 字段 | 说明 |
|------|------|
| `kind` | `voice` \| `text` \| `image` |
| `communityId` | 群聊为社群 ID；**私聊固定 `"direct"`** |
| `peerScopeKey` | **仅私聊**可选返回，会话对方 scope |
| `senderScopeKey` | `system` 为群助手（老人端 UI 不展示） |
| `durationMs` | 语音必填且 >0，避免前端显示假 1 秒 |
| `mine` | 相对当前查看者是否在右侧 |

### 3.3 MessagePage — 分页载荷

见 §2.3。

### 3.4 MembershipsResponse

```json
{
  "joinedCommunityIds": ["taiji", "calligraphy"],
  "scopeKey": "phone_13800138001"
}
```

### 3.5 CommunityJoinResult — 入群响应（前端）

`POST .../memberships` 的 `data` 建议包含：

```json
{
  "communityId": "taiji",
  "scopeKey": "phone_13800138001",
  "status": "active",
  "joinedAtMillis": 1712716200000,
  "welcomeMessage": "欢迎来到太极晨练群！可按住说话…"
}
```

| 字段 | 说明 |
|------|------|
| `welcomeMessage` | **入群瞬间弹窗/横幅用**，与消息列表分离；前端**不**把 `system` 欢迎当作普通消息展示 |

可同时写入 `interest_community_messages`（`sender_scope_key=system`）作留档，但 UI 以 `welcomeMessage` 为准。

### 3.6 ElderFriend — 已加好友

```json
{
  "scopeKey": "demo_peer_wang",
  "displayName": "王阿姨",
  "phone": "13800001101",
  "hint": "太极晨练群 · 常约公园晨练",
  "emoji": "👵",
  "addedAtMillis": 1712564400000
}
```

### 3.7 ElderFriendCandidate — 可添加候选（discover）

```json
{
  "scopeKey": "demo_peer_wang",
  "displayName": "王阿姨",
  "phone": "13800001101",
  "hint": "太极晨练群 · 常约公园晨练",
  "emoji": "👵"
}
```

### 3.8 ClearChatResponse — 清空群聊（软隐藏）

```json
{
  "communityId": "taiji",
  "viewerScopeKey": "phone_13800138001",
  "clearBeforeMillis": 1712800000000
}
```

### 3.9 ChildCommunityOverview — 子女总览项

```json
{
  "elderProfileId": 1,
  "elderDisplayName": "张建国",
  "communities": [
    {
      "community": { /* InterestCommunityBrief */ },
      "joined": true,
      "latestMessage": { /* CommunityMessage | null */ }
    }
  ]
}
```

## 4. 接口总览

### 4.1 老人端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/elder/interest-communities` | 社群目录 + `joined` |
| GET | `/v1/elder/interest-communities/memberships` | 已加入群 ID |
| POST | `/v1/elder/interest-communities/memberships` | 加入社群 |
| DELETE | `/v1/elder/interest-communities/memberships/{communityId}` | 退出社群 |
| GET | `/v1/elder/interest-communities/{communityId}/messages` | 群消息分页 |
| POST | `/v1/elder/interest-communities/{communityId}/messages` | 发文字 / 语音 / 图片 |
| DELETE | `/v1/elder/interest-communities/{communityId}/messages` | 清空群聊（仅当前用户视角） |
| GET | `/v1/elder/friends` | 好友列表 |
| GET | `/v1/elder/friends/discover` | 可添加候选（推荐 / 按手机号查） |
| POST | `/v1/elder/friends` | 添加好友 |
| DELETE | `/v1/elder/friends/{friendScopeKey}` | 删除好友 |
| GET | `/v1/elder/direct-messages/threads/{peerScopeKey}/messages` | 私聊历史分页 |
| POST | `/v1/elder/direct-messages/threads/{peerScopeKey}/messages` | 发私聊文字 / 语音 / 图片 |
| DELETE | `/v1/elder/direct-messages/threads/{peerScopeKey}/messages` | 清空私聊（仅当前用户视角，不删消息） |
| POST | `/v1/elder/profile/avatar` | 上传老人头像 |

### 4.2 媒体（群聊 + 私聊共用 messageId）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/community-voice/{messageId}/file` | 下载语音 m4a/aac |
| GET | `/v1/community-image/{messageId}/file` | 下载图片 |

`messageId` 在群聊表与私聊表间**全局唯一**；校验当前用户有权访问该消息。

### 4.3 子女端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/child/elders/{elderProfileId}/interest-communities` | 父母社群总览 + 最近一条消息 |
| GET | `/v1/child/elders/{elderProfileId}/interest-communities/{communityId}/messages` | 只读群消息分页 |
| DELETE | `/v1/child/elders/{elderProfileId}/interest-communities/{communityId}/messages` | 清空预览视角（软隐藏） |

子女端 **禁止** POST 发群消息。

## 5. 老人端 · 兴趣社群（群聊）

**前缀：** `/v1/elder/interest-communities`  
**Flutter：** `InterestCommunityApi`、`CommunityGroupChatService`、`CommunityMembershipRepository`

### 5.1 GET `/`

返回 `data: InterestCommunityBrief[]`。`joined` = 当前老人是否存在 `memberships.status=active`。

### 5.2 GET `/memberships`

返回 `data: MembershipsResponse`。

### 5.3 POST `/memberships`

**Body：**

```json
{ "communityId": "taiji" }
```

**服务端（建议事务）：**

1. 校验社群存在且 `is_active=1`
2. 写入/更新 `interest_community_memberships` → `active`
3. 可选：首条 `system` 欢迎消息入库
4. 若 `community_peer_seed_log` 无记录：播种演示群友消息
5. 返回入群摘要，**含 `welcomeMessage`**

### 5.4 DELETE `/memberships/{communityId}`

软退群 `status=left`，**不删** `interest_community_messages`。

### 5.5 GET `/{communityId}/messages`

- 须已 `active` 入群，否则 `403`
- 应用 `interest_community_chat_clear`：`createdAtMillis > clearBeforeMillis`
- 过滤：前端自行忽略 `senderScopeKey=system` 的展示
- 单群建议保留最近 **200** 条

### 5.6 POST `/{communityId}/messages`

**文字 — `application/json`：**

```json
{ "kind": "text", "textContent": "大家好，明天见" }
```

**语音 — `multipart/form-data`：**

| 字段 | 必填 | 说明 |
|------|------|------|
| `kind` | 是 | `voice` |
| `file` | 是 | m4a/aac，最短 **≥400ms** |
| `durationMs` | 否 | 客户端探测时长；未传则服务端解析 |

**图片 — `multipart/form-data`：**

| 字段 | 必填 | 说明 |
|------|------|------|
| `kind` | 是 | `image` |
| `file` | 是 | jpg/png/webp，建议 ≤5MB |

**响应 `data`：** 完整 `CommunityMessage`。

存储示例：

- 语音：`/uploads/community_voice/{uuid}.m4a`
- 图片：`/uploads/community_image/{uuid}.jpg`

### 5.7 DELETE `/{communityId}/messages`

软清空：UPSERT `interest_community_chat_clear(viewer_scope_key, community_id, clear_before_millis=now)`。  
**不**物理删除消息与媒体；**不**影响其他成员/子女独立视角。

## 6. 老人端 · 好友

**前缀：** `/v1/elder/friends`  
**Flutter：** `InterestCommunityApi.listFriends/discoverFriends/addFriend/removeFriend`、`CommunityFriendRepository`

### 6.1 GET `/`

`data: ElderFriend[]`，按 `added_at` **降序**。

### 6.2 GET `/discover`

**发现可添加的人**（不是好友列表）。

| 查询参数 | 说明 |
|----------|------|
| `phone` | 可选，11 位手机号**精确**匹配 |

| 调用 | 用途 |
|------|------|
| 无参数 | 「添加好友」页 **同群推荐** 列表 |
| `?phone=13800001101` | 按手机号添加前查人 |

`data: ElderFriendCandidate[]`。来源：`community_demo_peer_profiles`、已注册老人等；**不含自己**。

### 6.3 POST `/`

**Body（二选一）：**

```json
{ "phone": "13800001101" }
```

```json
{ "scopeKey": "demo_peer_wang" }
```

- 单向通讯录，无需对方确认
- 重复 → `409`
- 未知手机号：`scopeKey=phone_{phone}`，`displayName=手机尾号xxxx`

**响应 `data`：** `ElderFriend`。

### 6.4 DELETE `/{friendScopeKey}`

删除好友，对方无通知。路径需 `Uri.encodeComponent`。

## 7. 老人端 · 一对一私聊

**前缀：** `/v1/elder/direct-messages`  
**Flutter：** `InterestCommunityDirectApi`、`CommunityDirectChatService`、`CommunityDirectChatPage`

### 7.1 线程规则

- 路径参数 `peerScopeKey` = 对方 scope
- 库表线程键：`participant_a = min(A,B)`，`participant_b = max(A,B)`
- 禁止 `peerScopeKey == 当前用户 scope` → `4000`
- 首次发消息时 **自动创建** `direct_message_threads`
- 单线程保留最近 **200** 条

### 7.2 GET `/threads/{peerScopeKey}/messages`

分页同 §2.3。序列化建议：

- `communityId: "direct"`
- `peerScopeKey` = 路径参数
- `mine` 按当前老人 scope 计算

### 7.3 POST `/threads/{peerScopeKey}/messages`

发送规则 **与群聊 §5.6 相同**（文字 JSON / 语音·图片 multipart）。  
`sender_role=elder`。响应 `DirectMessage`（即 `CommunityMessage` + `peerScopeKey`）。

### 7.4 私聊清空
清空私聊对话记录（**软隐藏**）：不删除 `direct_messages` 与媒体文件，仅对当前查看者隐藏更早消息。

**接口：**

`DELETE /v1/elder/direct-messages/threads/{peerScopeKey}/messages`

**服务端语义：**

1. 解析当前登录 elder scope 作为 `scope_key`（即查看者视角）
2. `direct_message_clear` 按 `(thread_id, scope_key)` UPSERT：
   - 更新 `clear_before_millis = 当前毫秒时间戳`
3. 后续 `GET /threads/{peerScopeKey}/messages` 仅返回：
   - `direct_messages.created_at > clear_before_millis`

对方参与者有各自的 `scope_key`，因此不会被互相清空。

## 8. 老人端 · 头像（群聊 UI 依赖）

### POST `/v1/elder/profile/avatar`

**multipart：** `file`（jpg/png，建议 ≤2MB）

**响应：**

```json
{ "code": 0, "message": "success", "data": { "avatarUrl": "/uploads/avatars/xxx.jpg" } }
```

更新 `users.avatar_url`；后续消息 `senderAvatarUrl` 优先取该字段。

**Flutter：** `ElderAvatarRepository`（上传走 API，本地仅缓存文件路径供 UI）。

**展示优先级：** `senderAvatarUrl` → `senderEmoji` → 显示名首字。

## 9. 媒体文件下载

列表接口只返回 `audioUrl` / `imageUrl` 元数据；播放/大图由客户端带 JWT 下载：

```http
GET /api/v1/community-voice/{messageId}/file
GET /api/v1/community-image/{messageId}/file
```

- 响应：二进制流（非 JSON）
- 校验：消息存在且用户有权访问（入群成员 / 私聊线程参与方 / 子女绑定预览）

**Flutter：** `CommunityMediaDownloader` → `CommunityMediaCache` → 播放/展示。

## 10. 子女端 · 兴趣社群预览

**前缀：** `/v1/child/elders/{elderProfileId}/interest-communities`  
**Flutter：** `InterestCommunityApi.listChildOverview`、`listChildMessagesPage`、`clearChildChatHistory`

### 10.1 GET `/`

`data` 结构见 §3.9。仅 **已加入** 的群；按 `latestMessage.createdAt` 降序。

### 10.2 GET `/{communityId}/messages`

与老人端 GET 消息相同，但：

- `mine` 按 **绑定老人** 的 scope 计算（父母消息在右侧）
- 应用子女自己的 `interest_community_chat_clear`（`viewer_scope_key` 为子女侧标识）

### 10.3 DELETE `/{communityId}/messages`

同老人端软清空，仅影响当前子女对该老人的预览视角。

## 12. 业务规则与错误码

| 场景 | code | 说明 |
|------|------|------|
| 未入群发消息 / 拉消息 | 403 | 请先加入该社群 |
| 语音 < 400ms | 4000 | 录音时间太短 |
| 重复入群 | 409 | 已是群成员 |
| 重复加好友 | 409 | 已是好友 |
| 私聊对象为自己 | 4000 | 不能与自己私聊 |
| `limit` > 200 | 4000 | 参数超限 |

**点头像交互（产品）：**

| 操作 | 接口 |
|------|------|
| 加好友 | `POST /v1/elder/friends` |
| 发私聊 | 打开私聊页 → `GET/POST .../direct-messages/threads/{peerScopeKey}/messages` |
| 换自己头像 | `POST /v1/elder/profile/avatar` |

**实施顺序建议：** 目录 → 入群 → 群消息 → 媒体下载 → 好友 → 私聊 → 子女预览。
