# 讯飞语音撤回组员使用说明

本文档给组员联调老人端 SOS 语音撤回使用。

## 功能说明

老人端点击右上角“紧急求助”后，会弹出撤回倒计时底部弹窗。

流程：

1. 前端先调用后端创建求助单，拿到 `alertId`
2. 弹窗开始倒计时
3. TTS 播报“误触请说撤回”
4. 播报结束后启动讯飞流式语音听写
5. 识别到“撤回 / 取消 / 不要发”等关键词后，调用后端撤回接口
6. 如果倒计时结束仍未撤回，则调用立即发送接口

## 重要安全规则

讯飞 `APPID`、`APIKey`、`APISecret` 不要写进 Git。

正确做法：

- 项目负责人通过私聊、密码管理器或临时安全渠道发给组员
- 组员只在本机 `flutter run --dart-define=...` 命令里使用
- 不要把真实密钥写入 Markdown、Dart、YAML、脚本或截图提交到仓库

如果密钥已经在公开仓库、群公告或截图中泄露，建议去讯飞控制台轮换密钥。

## 前置条件

组员需要先确认：

1. 后端已经启动
2. 手机和电脑在同一网络，或手机连电脑热点
3. 手机已经允许 App 使用麦克风
4. 讯飞应用已开通“语音听写（流式版）WebAPI”
5. `APPID`、`APIKey`、`APISecret` 来自同一个讯飞应用

## 启动后端

新开一个 PowerShell：

```powershell
cd E:\SCEP-backend\backend
.\mvnw.cmd spring-boot:run
```

后端默认地址：

```text
http://localhost:8080/api
```

## 查询电脑 IP

如果是真机联调，先查电脑 IPv4：

```powershell
ipconfig
```

看 WLAN 或当前热点网卡的 `IPv4 Address`。

示例：

```text
10.24.58.8
```

手机浏览器可以先访问：

```text
http://电脑IPv4:8080/api/v1/health
```

如果手机浏览器打不开，App 也连不上后端。

## 真机运行命令

把下面命令中的占位符替换成真实值：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd pub get
.\flutterw.cmd run --dart-define=API_BASE=http://电脑IPv4:8080/api `
  --dart-define=XFYUN_IAT_APP_ID=你的APPID `
  --dart-define=XFYUN_IAT_API_KEY=你的APIKey `
  --dart-define=XFYUN_IAT_API_SECRET=你的APISecret
```

注意：

- `APIKey` 和 `APISecret` 不是同一个字段
- 不要把 `APISecret` 误填到 `APIKey`
- 当前默认讯飞端点是 `wss://iat-api.xfyun.cn/v2/iat`

## 模拟器运行命令

模拟器访问电脑后端用 `10.0.2.2`：

```powershell

  --dart-define=XFYUN_IAT_API_KEY=你的APIKey `
```

如果只想验证“语音触发撤回 -> 后端撤回成功”的业务闭环，可以不用讯飞，改用本地模拟 STT：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd run --dart-define=API_BASE=http://10.0.2.2:8080/api --dart-define=USE_MOCK_STT=true
```

## 常见问题

### 语音撤回不可用：讯飞配置缺失

说明 `flutter run` 没有传齐：

```text
XFYUN_IAT_APP_ID
XFYUN_IAT_API_KEY
XFYUN_IAT_API_SECRET
```

### 讯飞鉴权失败

优先检查：

- `APPID`、`APIKey`、`APISecret` 是否来自同一个应用
- 是否把 `APISecret` 填到了 `APIKey`
- 讯飞控制台是否开通了“语音听写（流式版）WebAPI”
- 手机时间是否明显不准，讯飞会校验 GMT 时间偏差

### 有 websocket ready，但没有识别文字

说明已经连上讯飞，但没有拿到有效识别结果。

优先检查：

- App 麦克风权限
- 手机是否真的有录音输入
- 是否在 TTS 播报结束后再说“撤回”
- 网络是否稳定

### 后端网络错误

优先检查：

- 后端是否启动
- `API_BASE` 里的 IP 是否是电脑当前 IPv4
- 手机和电脑是否在同一网络
- Windows 防火墙是否拦截 8080
