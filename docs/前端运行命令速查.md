# 前端运行命令速查

本文档记录本机常用的后端与 Flutter 前端启动命令。下次联调时可以直接复制。

## 1. 启动后端

先开一个 PowerShell：

```powershell
cd E:\SCEP-backend\backend
.\mvnw.cmd spring-boot:run
```

后端默认地址：

```text
http://localhost:8080/api
```

本机健康检查：

```powershell
Invoke-RestMethod http://localhost:8080/api/v1/health
```

如果返回 `unauthorized` 也说明服务通了，因为接口被鉴权拦住了。

## 2. Android 模拟器运行前端

模拟器访问电脑本机后端要用 `10.0.2.2`：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd pub get
.\flutterw.cmd run --dart-define=API_BASE=http://10.0.2.2:8080/api
```

如果只是想先验证 SOS “语音触发撤回 -> 后端撤回成功”的业务闭环，可以打开本地 STT mock：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd run --dart-define=API_BASE=http://10.0.2.2:8080/api --dart-define=USE_MOCK_STT=true
```

说明：

- `USE_MOCK_STT=true` 不调用 Android 系统语音识别服务
- 弹窗进入监听态后约 2.5 秒自动模拟识别到“撤回”
- 撤回接口仍然走真实后端
- 用来绕过模拟器 / 国产 ROM 的 `error_client`、`error_network` 问题

## 3. Android 真机：当前手机热点环境

2026-05-13 当前电脑连手机热点后，电脑 WLAN IPv4 是：

```text
10.24.58.8
```

真机运行命令：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd pub get
.\flutterw.cmd run --dart-define=API_BASE=http://10.24.58.8:8080/api
```

如果要测试真实讯飞语音撤回，把讯飞参数也带上。注意不要把真实密钥提交到 Git：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd run --dart-define=API_BASE=http://10.24.58.8:8080/api `
  --dart-define=XFYUN_IAT_APP_ID=你的APPID `
  --dart-define=XFYUN_IAT_API_KEY=你的APIKey `
  --dart-define=XFYUN_IAT_API_SECRET=你的APISecret
```

当前默认讯飞端点使用流式听写 v2：

```text
wss://iat-api.xfyun.cn/v2/iat
```

如果要按部分旧鉴权文档临时切到 v1，可额外加：

```powershell
  --dart-define=XFYUN_IAT_HOST=iat.xf-yun.com `
  --dart-define=XFYUN_IAT_PATH=/v1
```

手机浏览器连通性测试：

```text
http://10.24.58.8:8080/api/v1/health
```

如果手机浏览器打不开，App 也一定连不上。优先检查：

- 后端是否启动
- 手机是否还连着同一个热点/网络
- 电脑 IPv4 是否变化
- Windows 防火墙是否拦截 8080

## 4. Android 真机：重新查询电脑 IP

每次换 WiFi、换热点、重新连接网络后，先查电脑 IP：

```powershell
ipconfig
```

看这一项：

```text
Wireless LAN adapter WLAN
IPv4 Address
```

然后把命令里的 IP 换成新的 IPv4：

```powershell
cd E:\SECP-frontend\mobile
.\flutterw.cmd run --dart-define=API_BASE=http://你的电脑IPv4:8080/api
```

示例：

```powershell
.\flutterw.cmd run --dart-define=API_BASE=http://192.168.1.23:8080/api
```

## 6. Flutter 运行中的快捷键

在 `flutter run` 终端里：

```text
r  Hot reload
R  Hot restart
q  退出运行
```

如果改了原生权限、插件、AndroidManifest、Info.plist，建议用：

```text
q
```

退出后重新执行 `flutterw.cmd run`。

## 8. SOS 调试日志

当前 SOS 弹窗已经加了统一日志前缀：

```text
[SOS]
```

运行真机测试时，重点看 Flutter 终端里这些日志：

```text
[SOS] tap: createHelpRequest start ...
[SOS] createHelpRequest success alertId=...
[SOS] tts start ...
[SOS] tts completed ...
[SOS] xfyun websocket connect ...
[SOS] xfyun websocket ready ...
[SOS] xfyun record stream start ...
[SOS] speech recognized ... words="..."
[SOS] speech keyword check ... matched=true/false
[SOS] revoke submit start ...
[SOS] revoke submit success ...
```

如果显示 `语音撤回不可用：讯飞配置缺失`，说明本次 `flutter run` 没有传 `XFYUN_IAT_APP_ID`、`XFYUN_IAT_API_KEY`、`XFYUN_IAT_API_SECRET`。

如果没有 `xfyun websocket ready`，优先检查手机网络能否访问外网，以及讯飞密钥是否正确。

如果有 `xfyun websocket ready` 和 `xfyun record stream start`，但没有 `speech recognized`，说明录音已经开始，但讯飞没有返回文字，优先检查麦克风权限、手机是否有录音输入、说话时机是否在 TTS 播报结束之后。

如果有 `speech recognized` 但 `matched=false`，说明识别出来的文字没有命中撤回关键词，把识别结果补进关键词表即可。

如果 `revoke submit start` 后没有 success，说明卡在后端撤回接口或网络请求。

## 10. 语音撤回模式选择

真实讯飞 STT：

```powershell
.\flutterw.cmd run --dart-define=API_BASE=http://你的电脑IPv4:8080/api `
  --dart-define=XFYUN_IAT_APP_ID=你的APPID `
  --dart-define=XFYUN_IAT_API_KEY=你的APIKey `
  --dart-define=XFYUN_IAT_API_SECRET=你的APISecret
```

本地模拟 STT：

```powershell
.\flutterw.cmd run --dart-define=API_BASE=http://你的电脑IPv4:8080/api --dart-define=USE_MOCK_STT=true
```

选择规则：

- 真机验收语音能力：用真实讯飞 STT
- 只验证 SOS 后端撤回链路：用 `USE_MOCK_STT=true`
- 未传讯飞配置且未开 mock 时，语音行会显示“语音撤回不可用：讯飞配置缺失”，倒计时和按钮仍正常工作
